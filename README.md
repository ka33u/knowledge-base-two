# knowledge-base-two｜电机设计知识库

这是一个面向局域网协作的设计知识库。资料在浏览器中转换为适合阅读的网页内容，并由局域网服务统一保存、授权和同步。

## 支持格式

- Markdown、TXT、HTML：转换为适合阅读的 HTML
- DOCX：提取正文并转换为 HTML
- XLS/XLSX：所有工作表转换为 HTML 表格
- PDF：逐页渲染为高清网页预览
- PNG/JPG/GIF/WebP：在阅读器中完整显示
- PPTX：保留原文件并转换为网页幻灯片预览

浏览器会保留少量阅读缓存；局域网模式下，资料元数据、回收站和原始 PDF/PPTX/图片以服务端数据为准。重要资料仍建议按部署说明执行备份。

## 数据与权限说明

- 删除资料会先进入回收站，可恢复；在回收站再次删除才会永久清除附件。
- 搜索结果会高亮标题、摘要、分类和标签中的匹配内容。
- 内置管理员、编辑者、只读访客三种服务端角色，并由接口强制校验。
- 未登录访问主页会进入独立登录页；双击 `index.html` 时会跳转到本机服务的登录页。

生产化部署与后端迁移建议见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 局域网服务模式

需要 Node.js 25 或更高版本。运行 `npm run dev` 后，在局域网内通过 `http://服务器IP:8787` 访问；首次访问会创建管理员账号。资料、回收站和原始 PDF/PPTX/图片均保存在服务器，数据库位于 `data/knowledge.db`，附件位于 `data/attachments/`，请将两者一起纳入备份。单个原始附件上限为 100MB；转换后的 HTML 内容上限为 10MB。管理员可管理账号、重置密码；用户可自行修改密码。

## 回归测试

执行 `npm test` 可在临时目录启动隔离服务，并自动验证登录、分类、账号、资料、附件、回收站恢复和永久删除；测试不会接触正式 `data/` 目录。
